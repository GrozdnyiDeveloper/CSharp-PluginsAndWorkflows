# Плагины и кастомные шаги
В данном репозитории представлены примеры разработанных плагинов и кастомных шагов для системы Dynamics 365 в рамках отдельных решений (сборок) на C#. 
Данные компоненты были реализованы в рамках задач по расширению функциональности системы Dynamics 365. 

## ExamplePlugins - Сборка, содержащая примеры плагинов для Dynamics 365
- CreateTaskForLead - Плагин создающий Задачу для новосозданной записи Интереса
- DeleteChildOrganizations - Плагин добавляющий для всех дочерних организаций текст в их описание об удалении родительской записи
- ReAssignIncident - Плагин при переназначении Обращения создаёт Примечание с пометкой на то, кому оно было назначено, а также переназначает все дочерние Обращения
- SetStateOpportunity - Плагин в зависимости от смены статуса заявки Возможной сделки устанавливает значение поля "Текущая ситуация"
- SynchronizeTenderAndRequest - Плагин производящий синхронизацию данных записей сущностей Тендер и Запрос и дочерних к ним записей Продуктов и Примечаний
- UpdateOpportunity - Плагин логгирует в описание записи Возможной сделки изменения поля "Текущая ситуация"
- UpdatePhoneForContact - Плагин проверяет корректность введённых номеров телефона в контакте и меняет их под формат

## ExamplePlugins - Сборка, содержащая примеры кастомных шагов для Dynamics 365
- CalculateDiscountForExternalProject - Кастомный шаг вычисляющий средний процент скидки по продуктам Внешнего проекта, отфильтрованным по направлению деятельности
- CalculateDiscountForTender - Кастомный шаг вычисляющий средний процент требуемой скидки по продуктам Тендера, отфильтрованным по направлению деятельности через родительский продукт
- CheckTenderBySystemCode - Кастомный шаг проверяющий уникальность Тендера по коду внешней системы
- FormJSONForTender - Кастомный шаг собирающий полную информацию о Тендере (сам тендер + связанные регион, партнёр, контакт, продукты) и формирующий из неё JSON-сообщение для интеграции с внешней системой
- GetTaxWorkflow - Кастомный шаг считывающий значение налоговой ставки из кастомной сущности Конфигурации по ключу и возвращающий его как строку
- GetTenderWorkflow - Кастомный шаг находящий Тендер по строковому GUID и возвращающий на него ссылку
- StartWorkflow - Кастомный шаг запускающий Workflow (по переданной ссылке) для указанной записи Заявки от имени администратора
- TrigerAnActionAsUser - Кастомный шаг запускающий Custom Action или Workflow для указанной записи Тендера от имени указанного пользователя
