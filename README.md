# Плагины и кастомные шаги
В данном репозитории представлены примеры разработанных плагинов и кастомных шагов для системы Dynamics 365 в рамках отдельных решений (сборок) на C#. 
Данные компоненты были реализованы в рамках задачи по расширению функциональности сущности Проектных блоков в системе Dynamics 365. 

**Архив имеет следующее содержимое:**
- Dynamics.Plugins - Проект, содержащий разработанные плагины для сущностей external_projects и opportunityproduct системы Dynamics 365
- Project.Workflows.Entity - Проект, содержащий разработанные кастомные шаги для сущности inner_branch системы Dynamics 365
